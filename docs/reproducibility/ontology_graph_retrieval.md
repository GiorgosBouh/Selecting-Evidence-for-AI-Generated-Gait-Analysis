# Ontology-Guided Retrieval (OGR) method note

The manuscript describes OGR as matching case features to concepts in the Gait Analysis Domain Ontology (GADO), expanding those concepts through subclass and object-property domain/range links, and selecting up to three evidence units from an ontology-linked corpus. The same generation prompt and support checks were intended to be used across the three main methods.

## Release limitation

This folder does not contain the OGR implementation, the GADO OWL file, the study-specific feature-to-GADO mapping, the normalized OGR evidence corpus, or the final primary-prompt OGR output file. Those materials were referenced in earlier project notes but were not present in the source directories available when this release folder was assembled. Consequently, this document records the described method but does not enable an independent rerun or verification of the OGR results. The corresponding source files and output records must be added before the repository can support the manuscript's full three-method reproducibility claim.

The OGR values reported in the manuscript and supplementary tables should be checked against the original run artifacts before submission.
